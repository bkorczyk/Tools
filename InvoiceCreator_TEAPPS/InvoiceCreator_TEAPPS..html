Dokumentacja Aplikacji: Generator Faktur TEAPPS 3.0

Dokumentacja aplikacji webowej Flask do parsowania zamówień PO, generowania e-faktur w formacie TEAPPSXML 3.0 oraz automatycznej wysyłki plików na serwer FTP Basware.

1. Opis Programu

Aplikacja umożliwia weryfikację i generowanie plików faktur w dwóch podstawowych trybach:

  • Debit Invoice: Wystawianie faktury debetowej wyłącznie na podstawie ręcznie wprowadzonych danych nagłówkowych.
  • Purchase Order Invoice: Wgrywanie plików zamówień XML (np. Order_Template.xml.bak), dynamiczne wyliczanie wartości pozycji odbiorów (GR) oraz dopasowywanie kwot.

Program posiada wbudowany moduł pobierania plików XML na dysk lokalny oraz moduł automatycznej transmisji FTP do systemu Basware.

2. Wymagania Wdrożeniowe

  • Środowisko: Python 3.10+
  • Zależności zewnętrzne: Flask, python-dotenv
  • Biblioteki standardowe: csv, datetime, ftplib, io, os, re, xml.etree.ElementTree

3. API i Endpointy Server-side

Endpoint Metoda Opis
/api/upload POST Wgrywanie i parsowanie pliku zamówienia XML (PO)
/api/delete-order/<id> DELETE Usuwanie zamówienia z bieżącej sesji aplikacji
/api/generate-xml POST Generowanie i pobieranie pliku XML z fakturą TEAPPS 3.0
/api/send-to-basware POST Generowanie XML w RAM i bezpośrednie wysłanie na FTP Basware

4. Konfiguracja Środowiskowa (.env)

Dane dostępowe do serwera FTP należy zdefiniować w pliku .env w katalogu głównym projektu:

FTP_HOST=ftp.basware.com
FTP_USER=twój_login
FTP_PASS=twoje_haslo
FTP_PORT=21
FTP_DIR=/inbound

5. Instrukcja Obsługi

a) Uruchomienie serwera:

python InvoiceCreator_TEAPPS.py

b) Generowanie i pobranie faktury:

Wypełnij formularz w przeglądarce pod adresem http://127.0.0.1:5000/ i kliknij przycisk Pobierz Fakturę TEAPPS 3.0 (XML).

c) Wysyłka bezpośrednio do Basware:

Kliknij niebieski przycisk Wyślij do Basware (FTP). System przekaże plik bez zrzucania go na lokalny dysk i wyświetli komunikat o statusie połączenia.
