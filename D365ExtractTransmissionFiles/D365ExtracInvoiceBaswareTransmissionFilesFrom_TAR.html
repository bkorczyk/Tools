Dokumentacja Skryptu: Ekstraktor Faktur D365 v2

Dokumentacja skryptu Python do przeszukiwania i ekstrakcji plików XML z archiwów TAR / TAR.GZ / TGZ z obsługą listy faktur z CLI, plików CSV oraz filtra pełnego.

1. Opis Programu

Skrypt automatycznie przeszukuje archiwa skompresowane i wyciąga pliki integracyjne XML systemu Dynamics 365. Numery faktur można przekazać na 3 sposoby:

  • Lista bezpośrednio z wiersza poleceń (CLI): ciąg znaków oddzielony przecinkami (np. "FV100, FV101, FV102").
  • Plik CSV: ścieżka do pliku zawierającego listę faktur.
  • Pełna ekstrakcja ("*"): wypakowuje wszystkie znalezione faktury.

2. Wymagania Wdrożeniowe

  • Środowisko: Python 3.10+
  • Biblioteki standardowe: argparse, csv, os, re, tarfile, xml.etree.ElementTree.

3. Składnia CLI i Parametry

python script.py <tar_file> <invoices_param> [-o OUTPUT_DIR]
Parametr Typ Opis
tar_file Wymagany Ścieżka do archiwum (.tar, .tar.gz, .tgz)
invoices_param Wymagany Lista po przecinku "faktura1, faktura2" LUB ścieżka do CSV LUB "*"
-o, --output Opcjonalny Katalog docelowy (domyślnie: ./extracted_invoices)

4. Przykłady Użycia

a) Podanie listy faktur w wierszu poleceń:

python script.py archiwum.tar.gz "17360, 17361, 17362"

b) Użycie pliku CSV:

python script.py archiwum.tar.gz plik_faktur.csv

c) Wypakowanie wszystkich faktur do wskazanego folderu:

python script.py archiwum.tgz "*" -o ./wszystkie_wyjscie
