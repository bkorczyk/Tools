Dokumentacja Aplikacji: Dynamiczna Mapa Myśli XSD

Dokumentacja aplikacji webowej Python (Flask) oraz JavaScript (D3.js) przeznaczonej do interaktywnej, dynamicznej wizualizacji i analizy struktur plików schematów XML (XSD).

1. Opis Programu

Aplikacja służy do wizualizacji struktury drzeiwiastej schematów XSD w postaci mapy myśli. Pozwala użytkownikowi na wczytanie pliku XSD bezpośrednio z poziomu przeglądarki i dynamiczne rozwijanie kolejnych węzłów po kliknięciu.

  • Wczytywanie Drag & Drop: Bezpośrednie przeciąganie plików .xsd do okna przeglądarki.
  • Dynamiczne doczytywanie (Lazy Loading): Drzewo renderuje tylko aktywne gałęzie, zapobiegając zawieszaniu przeglądarki przy bardzo dużych plikach.
  • Interaktywny graf D3.js: Obsługa powiększania/przesuwania (Zoom/Pan), zwijania i rozwijania gałęzi oraz animowanych przejść.

2. Wymagania Wdrożeniowe

  • Środowisko: Python 3.10+
  • Przeglądarka internetowa z obsługą JavaScript ES6 i SVG (Chrome, Edge, Firefox).
  • Wymagane pakiety Pythona: flask, xmlschema.

3. Punkty Końcowe API (Endpoints)

Serwer domyślnie uruchamia się pod adresem: http://127.0.0.1:5000
Metoda Endpoint Opis
POST /api/upload Odbiera plik XSD przesłany przez formularz, parsuje go i zwraca korzeń schematu.
GET /api/root Zwraca dane dotyczące głównego węzła aktualnie załadowanego schematu.
GET /api/children/<path> Dynamicznie pobiera listę bezpośrednich potomków dla wskazanej ścieżki węzła.

4. Przykłady Użycia

a) Uruchomienie aplikacji:

python XSDMindMap.py

b) Interakcja w przeglądarce:

1. Otwórz adres http://127.0.0.1:5000 w przeglądarce.
2. Przeciągnij plik .xsd w wyznaczone pole.
3. Klikaj na poszczególne węzły, aby stopniowo odkrywać gałęzie schematu XSD.
